# Changelog

## [1.0.0] - 2026-10-02

First release.

- Gate with an open/closed light
- Mid-hump overdrive (clips only above ~720 Hz) with Drive, Tone and Level
- Cascaded master-volume British head with a circuit-derived tone stack (double precision), EL34-style power stage and Presence
- 4x12 cab; default EQ fitted to a reference recording (Bass 9, Middle 1, Treble 3, Presence 7)
- Plate reverb, stereo output
- Amp + Cab bypass, INIT button, knob shortcuts
- 4x oversampled, VST3 and Standalone for Windows 64-bit
